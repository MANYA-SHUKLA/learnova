# Course Builder Guide

## Overview

The Course Builder enables faculty and administrators to create structured, engaging learning experiences. This guide covers best practices for course design and content creation.

## Course Creation Workflow

### 1. Plan Your Course
Before creating a course in the system:
- Define learning objectives
- Identify prerequisites
- Plan module structure
- Estimate time commitment
- Gather or create content materials

### 2. Create Course Shell
- Set course code and title
- Write clear description
- Define credit hours
- Add objectives and prerequisites
- Set department/program/semester associations
- Add relevant tags for discoverability

### 3. Structure with Modules
Break your course into logical modules:
- Introduction/Overview module
- Core content modules (typically 4-8 modules)
- Assessment/Review module
- Each module should cover a major topic or skill

### 4. Populate with Lessons
Within each module, create lessons:
- Keep lessons focused (10-30 minutes each)
- Mix content types (video, reading, interactive)
- Sequence from simple to complex
- Include knowledge checks

### 5. Publish and Iterate
- Review all content before publishing
- Publish when ready for student access
- Collect feedback and iterate
- Update content based on student performance

## Content Type Best Practices

### Video Lessons
- Keep videos 5-15 minutes
- Include timestamps for key sections
- Provide captions/transcripts
- Use consistent format/quality

### Reading Materials (PDF/Markdown)
- Structure with clear headings
- Include summaries and key takeaways
- Link to additional resources
- Optimize for mobile viewing

### Interactive Content (HTML/Embed)
- Test across devices and browsers
- Ensure responsive design
- Provide clear instructions
- Include fallback content

### Code Lessons
- Use syntax highlighting
- Provide working examples
- Include explanatory comments
- Offer downloadable code

## Course Design Principles

### Progressive Disclosure
- Start with fundamentals
- Build complexity gradually
- Revisit concepts with increasing depth
- Provide scaffolded support

### Active Learning
- Include interactive elements
- Pose questions throughout
- Encourage practice and application
- Provide immediate feedback

### Clear Navigation
- Use descriptive module/lesson titles
- Number lessons logically
- Provide course roadmap
- Show progress indicators

### Accessibility
- Add alt text to images
- Provide transcripts for audio/video
- Use clear, simple language
- Ensure color contrast
- Test with screen readers
